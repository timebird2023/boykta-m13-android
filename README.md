# Boykta M13 — بويكتا المساعد الصوتي بدون إنترنت (armeabi-v7a)

مشروع Android Kotlin متكامل لهاتف **Samsung Galaxy M13** بمعمارية `armeabi-v7a` يعمل 24/24 بصوت ذكوري عربي إجباري مع روبوت تفاعلي وتحكم شامل بالهاتف.

## المزايا الرئيسية (الإصدار 2.0)
- **روبوت تفاعلي حقيقي على الشاشة (`BoyktaRobotView.kt`)**: يرمش، يتفاعل بالموجات الصوتية أثناء الكلام، ويفرح عند تنفيذ الأوامر.
- **حزمتا صوت عربيتان على بطاقة 8GB SD**: الفصحى الدقيقة (`vosk-model-ar-mgb2` · 318MB) + الدارجة الجزائرية/المغاربية (`vosk-model-small-ar-tn` · 158MB).
- **تحكم شامل في الهاتف (`BoyktaAccessibilityService.kt`)**: الرجوع للخلف، الرئيسية، الإشعارات، تصوير الشاشة، قفل الشاشة، وتعديل السطوع، مع الضغط على الأزرار الظاهرة.
- **فهم ذكي وسط الضحك والكلام الجانبي**: يستخرج النية حتى لو قلت "بويكتا افتح فري فاير هههه خويا اسمع" وبشخصية جزائرية طبيعية.
