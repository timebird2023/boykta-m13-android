# Boykta M13 — بويكتا المساعد الصوتي بدون إنترنت (armeabi-v7a)

مشروع Android Kotlin متكامل لهاتف **Samsung Galaxy M13** بمعمارية `armeabi-v7a` يعمل 24/24 بصوت ذكوري عربي **مدمج بالكامل داخل التطبيق (Sherpa-ONNX Kareem)** مع استجابة فورية لكلمة **"بويكتا"** بنفس أسلوب OK Google.

## المزايا الرئيسية (الإصدار 3.0)
- **صوت عربي ذكوري مدمج داخل التطبيق (`InAppArabicTtsEngine.kt`)**: يعتمد على محرك **Sherpa-ONNX** وصوت **كرم (`ar_JO-kareem-low`, ~64MB)** لتحدث بويكتا بالعربية 100% أوفلاين حتى لو كان هاتفك لا يحتوي إلا على صوت إنجليزي!
- **استجابة فورية لكلمة "بويكتا" (OK Google Style)**:
  - تعرّف متسامح مع نطق كلمة "بويكتا" (`WakeWordMatcher.kt`) في النتائج اللحظية (`onPartialResult`) + رنة تنبيه + اهتزاز + نافذة منبثقة في أسفل الشاشة.
  - إعادة تحميل تلقائية لنموذج السمع (158MB أو 318MB) فور اكتمال التحميل، مع عرض حي لما يسمعه الميكروفون الآن.
  - إيقاف مؤقت تلقائي للميكروفون أثناء كلام بويكتا لمنع الصدى، ثم العودة للاستماع 24/24.
