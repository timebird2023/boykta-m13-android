# Boykta M13 — بويكتا المساعد الصوتي بدون إنترنت (armeabi-v7a)

مشروع Android Kotlin متكامل لهاتف **Samsung Galaxy M13** بمعمارية `armeabi-v7a` يعمل 24/24 بصوت ذكوري عربي فصيح عالي الوضوح **مدمج بالكامل داخل التطبيق (Sherpa-ONNX Miro V2 High)** مع محرك سمع عصبي **Moonshine Arabic + Silero VAD v5**.

## المزايا الرئيسية (الإصدار 4.1)
- **نطق فصيح متنوع وشخصية ذكية (`BoyktaUserProfileStore.kt` & `DarijaIntentRouter.kt`)**: يرد بأسلوب مقتضب ومتغير وينادي المستخدم باسمه مع فهم الأوامر المركبة.
- **قراءة اسم المتصل أو رقمه وقراءة الرسائل المتكررة (`CallAnnouncerReceiver.kt` & `BoyktaNotificationListener.kt`)**: يقرأ اسم المتصل أو أرقام هاتفه مباشرة، وينبّه عند بقاء رسالة غير مقروءة من جهة متكررة دون قراءة نصها.
- **منبه التذكيرات الناطق (`BoyktaReminderStore.kt` & `BoyktaReminderReceiver.kt`)**: ينطق التذكير الذي كتبته بالاسم والوصف في الموعد المحدد.
- **حارس البطارية والبلوتوث والواي فاي (`BoyktaBackgroundService.kt`)**: ينبه عند الشحن المنخفض أو اكتماله (باستثناء الليل) ويغلق أو ينبه عند ترك البلوتوث أو الواي فاي مفتوحاً دون اتصال.
